# omodachi-ios docs

This repository keeps no long-form product documentation. What lives here
stays next to the code it describes.

- [`THIRD-PARTY.md`](THIRD-PARTY.md) — everything shipped inside the app
  bundle, with its origin, its hash and its licence.
- [`../Vendor/Moonlight/PATCHES.md`](../Vendor/Moonlight/PATCHES.md) — every
  local change against upstream Moonlight iOS 9.0.2, with provenance.
- [`../Tools/SSHFixture/README.md`](../Tools/SSHFixture/README.md) — the
  loopback SSH fixture the integration tests drive.
- [`../README.md`](../README.md) — what the app is, how to build it, and what
  the licence question is.

The host side of the same system is documented in
[`omodachi-core/docs/`](https://github.com/omodachi/omodachi-core/tree/main/docs).
